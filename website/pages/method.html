ROBUST PREDICTION

缺失鲁棒预测

针对局部连续片段缺失，构建可靠性感知多模态网络，并融合 BERT LoRA 文本专家。分类与回归分别预测情感极性和连续强度。

研究动机

局部连续缺失同时改变可用信息与观测分布。为保留三模态的原始对齐关系，模型保留缺失位置，通过观测掩码区分非零观测与缺失位置；有效长度内的全零观测也被视为未观测，并从可见模态读取补充信息。

使用 CMU-MOSEI 衍生子集的 aligned_50 预提取特征，训练 / 验证 / 历史留出划分为 3,395 / 728 / 727。词级对齐辅助流程的自提取特征不进入预测模型。

模型结构

缺失处理
保留位置、更新观测掩码；跨模态注意力仅使用可见 key / value，整模态缺失时该门控权重为零。
训练与选择
学习参数在训练集拟合；模型选择、融合系数和类别偏置在验证集确定。
参数范围
约 1.51 M 是单个 RM 核心的参数量，不包含 BERT 基座、LoRA 专家与整个集成。

双视图训练

原始观测与人工遮挡后的受损观测构成两个视图，共享 RM-Net 参数。联合目标包含极性与强度监督、人工遮挡位置的特征重建及视图一致性约束。

渐进式片段遮挡用于构造受损视图：训练前 30% 阶段将缺失率上限从 0.3 逐步提高至 1；每次选择 1–3 个模态、1–2 段连续区间，并以 20% 概率保留原视图。

文本可用度约束融合

令 f 为有效内容位置中可见且非 UNK 的比例。分类与回归采用独立的文本专家权重，最终类别由概率最大项决定。

w_{\mathrm{c}} = 0.8f^2,\qquad w_{\mathrm{r}} = 0.6f^2
p = \operatorname{softmax}\!\left(\log\!\left(\operatorname{clip}\!\left((1-w_{\mathrm{c}})p_{\mathrm{RM}} + w_{\mathrm{c}}p_{\mathrm{LoRA}},\,10^{-12},\,1\right)\right) + b\right)
\hat{y} = (1-w_{\mathrm{r}})\hat{y}_{\mathrm{RM}} + w_{\mathrm{r}}\hat{y}_{\mathrm{LoRA}}
b = (0.25,\,0,\,0.025)

类别顺序：负向、中性、正向。

滑块表示固定融合公式中权重随文本可用比例的变化。

分类专家权重80.0%
回归专家权重60.0%

f = 0 时专家权重为零，回归退回 RM 强度；分类仍保留固定偏置。各模型先 softmax 再平均，不平均 logits。独立分类与回归允许出现“强度为正、类别为中性”。
