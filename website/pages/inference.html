模型与算法

  
RM 分支集成种子 17、29、43、71、101 的五个模型；文本分支使用同一 BERT 基座上的五组 LoRA。各分支先对类别概率取均值，再按文本可用度融合，并应用验证集冻结的类别偏置。

  
w_{\mathrm{c}} = 0.8f^2,\qquad w_{\mathrm{r}} = 0.6f^2
p = \operatorname{softmax}\!\left(\log\!\left((1-w_{\mathrm{c}})p_{\mathrm{RM}}+w_{\mathrm{c}}p_{\mathrm{LoRA}}\right)+b\right)
\hat{y} = (1-w_{\mathrm{r}})\hat{y}_{\mathrm{RM}} + w_{\mathrm{r}}\hat{y}_{\mathrm{LoRA}}

  
f 为可见内容词元比例；UNK 不计入可用内容，PAD、CLS、SEP 不计入分母。b = (0.25, 0, 0.025)，依次对应负向、中性、正向。BERT 基座以 FP16 存储、FP32 运算，LoRA 保留 FP32；导出精度与论文 Python 入口的差异见验证记录。

  
推理通过 Web Worker 中的 ONNX Runtime Web 执行，使用本机 CPU。模型首次加载后尝试存入浏览器缓存；缓存不可用时仍可在线下载运行。停止计算会终止工作线程；清空会释放模型和当前输入。

输入协议

  
完整三模态输入采用论文的 50 位置对齐特征。当前页面接受英文文本或已提取的对齐特征；原始音视频不能直接输入；独立词级对齐流程的特征也不能替代此协议的预提取特征。
