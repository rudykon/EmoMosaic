# EmoMosaic code

- `src/p2p3/`: prediction, training, evaluation, missingness and explanations.
- `src/problem1/`: independent feature extraction and word-level alignment.
- `src/common/`: shared visualization and archive utilities.

Run commands from the repository root; see the [project README](../README.md).
Download model assets and data separately. Neither `models/` nor `outputs/`
is distributed through GitHub. Historical analysis tools require locally rebuilt
experiment outputs, and do not imply those outputs are included.
