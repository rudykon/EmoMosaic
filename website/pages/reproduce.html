REPRODUCTION & RESOURCES

复现说明

从公开源码、固定版本权重与数据开始，运行冻结的 RM-Net + BERT LoRA 模型。

运行环境

Python 3.11 · CPU / CUDA

以下命令对应当前 GitHub 代码仓库。模型权重与数据分别从 Hugging Face 下载，下载脚本固定版本并校验 SHA-256。

代码与依赖

BASH
git clone https://github.com/rudykon/EmoMosaic.git
cd EmoMosaic
python3.11 -m venv .venv
.venv/bin/python -m pip install --upgrade pip
.venv/bin/python -m pip install torch==2.6.0 --index-url https://download.pytorch.org/whl/cpu
.venv/bin/python -m pip install -r requirements.txt

下载资源与预测

BASH
make download-weights
make download-models
make download-data
make predict

数据约 3.80 GiB，公开下载无需令牌。输出文件为 validation/attachment3_predictions.csv，包含 30 条无标签样本的预测，不用于计算准确率。

重建特征与评估

BASH
.venv/bin/python code/src/p2p3/prepare.py --device cpu
make evaluate
make test
make check-weights

历史留出集曾在开发阶段被查看，不属于独立盲测。训练、评估及历史分析需要各自的输入文件；完整说明以仓库 README 为准。
